# Reference

Source material for the game's art — **not** shipped in the build (this folder
is outside `public/`).

- **`beryl.png`** — the original photo of Beryl, a turquoise 1960s Morris Minor
  1000. This is the visual reference the in-game sprite is based on (colours:
  turquoise body, whitewall tyres, chrome bumpers, red side pinstripe).

The in-game Beryl is currently drawn procedurally in `src/art.js`. If you later
generate a top-down sprite (e.g. via an image-generator agent), use this photo
as the reference and follow the swap-in steps in
`public/assets/README.md`.
